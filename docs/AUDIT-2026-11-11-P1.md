## 4 · C7 and C8 — merge commits

**The defect, measured on `25c9e79`:** a merge commit was given an empty file list, so content a merge adds itself — a
conflict resolution, or an edit made inside an uncommitted merge (the second route of `docs/AUDIT-2026-11-11.md` §1.3) — was seen
by no condition: C8 (S5 of that audit), C7 (a `Proposal:` on a merge was skipped whatever it carried), C6 (a ledger rewritten
inside a merge), and `tools/commit-evidence.mjs` (exempted as content "judged on their own").

**What a merge changed itself** — `tools/commit-evidence.mjs mergeOwnFiles()`, one home, used by the gate:

| Merge shape (tested on temporary repositories) | `diff-tree --cc` | `--remerge-diff` | own content (both) |
|---|---|---|---|
| both branches edit one file in different places, clean | **the file** (false positive) | none | **none** |
| a conflict resolved by taking one side wholesale | none | the file | **none** |
| a conflict resolved with new text | the file | the file | **the file** |
| a new file, or an edit, made inside the merge | the file | the file | **the file** |

An octopus merge has no remerge diff; the `--cc` list is used (wider, never narrower). Git that cannot answer → `files: null`
→ **C2 fails** (unmeasured is never empty). `--remerge-diff` needs git ≥ 2.36; the CI runner has 2.56.0 (§1).

**What each condition now does with it** — each applies its **existing** rule; no threshold, mode or decision changed:
C6 holds append-only against **every** parent of a merge; C7 refuses a merge that declares a `Proposal` and carries content
of its own (a dispatched change is a one-parent commit: dispatch stage 9 refuses a second parent) and ignores one with none;
C8 counts an agent-marked merge by its own published content — **still a warning; C8 strict stays off** (D-P0.4-2, unchanged);
`commit-evidence.mjs` keeps the author's rule (non-merge commits) and **reports** a merge's own published content (`!` lines).

**Impact on the real history (0338b0c..25c9e79: 205 commits, 35 merges), old and new gate side by side:** C5, C6, C7, C8
verdicts identical; C8 lists the same **8** commits (the audit of 11 Nov measured 6 at `ad234aa`; the two more are #98's own
