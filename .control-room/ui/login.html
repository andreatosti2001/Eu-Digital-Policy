Control Room

The European Legal Framework for the Digital World — private control plane.

You will be sent to the configured OpenID Connect provider. Multi-factor authentication, password policy and account recovery are handled there.

Development provider. It runs only on loopback, only with CONTROL_ROOM_ENV=development, and the server refuses to start in any other shape. There is no default account: the first administrator is created with node .control-room/cli.mjs provision.
